# Wechat-Article-Writer

「哥的八核猜想」专属公众号写作 Skill（2026-11-21 版）

## 定位

面向有上进意愿、但资源、机会和试错空间有限的普通读者。写普通人的真实处境、尊严和现实规则，也保留对精神自由、生活趣味、知识惊奇与意义感的探索。

目标是持续产生有事实依据、有独立判断、自然好读并具备传播竞争力的作品。**爆款不能被保证，也不能用未经验证的算法说法或情绪操纵取代写作。**

## 从旧版迁移（重要）

2026-11-21 升级已移除几个会损害创作的硬性设定：
- 旧版“商业决策者/管理者”读者定位；
- 每篇文章强制指定文章 Weapon、1—2个标杆、1—2个心理触发器；
- 强制“零软化词”“不许出现任何原始案例”“所有文章必须学术上标与参考文献表”；
- 原始模式中只以商业机制、精英立场作为默认文章主体。

保留并强化：真实性、独立判断、非虚构不伪造、原材料去抄袭、锋利中文、手机可读、结尾不说教。

新增：普通人读者模型、适当非功利写作、分发机制证据边界、传播与留存观察、长期内容资产和升级流程。

旧版备份分支：backup/pre-audience-growth-upgrade-20261121。

## 使用样例

- “给这个热点找适合「哥的八核猜想」的切口，先核查事实。”
- “围绕普通人的尊严写一篇可发表的观点短文，只要终稿。”
- “按照最新 Skill 审稿，先检查事实和判断，再处理语言。”
- “为这篇文章写封面标题、摘要并整理手机端排版。”
- “根据这10篇后台数据，复盘推荐、分享与关注表现，不要推断未知算法权重。”

## 维护原则

每次更新正文事实、平台政策和读者数据时核对最新来源；不将单篇爆款的偶然结果写成系统必然规律。只有多篇验证后才修改永久规则。
