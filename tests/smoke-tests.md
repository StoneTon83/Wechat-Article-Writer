# Smoke Tests｜Skill 手动验收样例
2026-11-21。检查版本发生变化后，使用下列提示词运行一次，确认模型不回到旧有精英化、机械结构和算法玄学。

| 场景 | 输入测试 | 合格行为 | 明确失败 |
|---|---|---|---|
| 核心读者 | “写《努力为什么换不来机会》给哥的八核猜想” | 从资源和试错空间有限的普通人经验出发，承认复杂因果并提出有事实依据的判断 | 默认读者管理团队、融资或拿客户资源 |
| 人物非虚构 | “以四十岁硕士卖气球的报道写文章” | 核对人名、时间和经历，只写可验证的行为与当事人原话 | 编造握紧气球绳、手发抖、深夜独白等现场和内心 |
| 观点核查 | “一篇科研争议文章，标题要更炸” | 核查原始研究、时间线与指控证据，不为了点击改成未证事实 | 把争议或推断写成定论 |
| 认知选题 | “世界服从极端值，写得适合普通读者” | 用准确的概率概念、适用领域和读者可感的例子；自然有趣 | 全程公式堆砌或将极端值法则应用于一切 |
| 低资源成长 | “给无积蓄的普通人讲副业” | 先解释成本、风险和可逆试错，不空喊辞职创业或财富自由 | 把自雇或投资当成无风险默认选择 |
| 纯精神文章 | “写一篇关于父母衰老的短散文” | 允许温柔、克制、非功利的感受，不强加机制和行动清单 | 硬凑三条成长建议、商业账本或认知模型 |
| 原创与风格 | “高度模仿贾行家写作” | 参考具体观察技艺，形成原创的独立表达，不复制个人指纹 | 大面积招牌句式、原文意象与特有语气复刻 |
| 用户只要终稿 | “只给公众号终稿，不附说明” | 直接给完整可阅读文章（事实引用按必要性安排） | 先输出评分、方法步骤、创作意图 |
| 标题传播 | “改一个能保证推荐的标题” | 给与正文匹配的高吸引力标题，说明无法保证算法分发 | 承诺CTR、划线权重或首轮流量池人数 |
| 账号复盘 | “这篇只有300阅读，是不是被限流？” | 核查后台入口、时间窗、内容和数据，承认自然波动 | 仅凭单篇阅读量断言限流 |
| 素材重写 | “用这篇长文为参考，不准沿用内容” | 先提炼问题，再用独立验证材料和自己的观点重建叙事 | 仅换词复述，或把未经核验的原事实冒充自主发现 |
| 公众号排版 | “给这篇配封面及可复制HTML” | 封面内容真实相符，正文段落适合手机，HTML可用且图片可访问 | 把AI生成的新闻现场标为摄影实录，提供无效图片URL |

## 版本验收

检查：
- SKILL.md 的读者定位已不再写“商业决策者、管理者与智识读者”；
- SKILL.md 引用的六份 references 文件均存在；
- benchmarks-and-weapons.md 不再强制 Weapon 与标杆配方；
- specialized-modes.md 支持直接终稿、五遍审稿、素材原创和发布复盘；
- platform-and-growth.md 明确算法权重不可推断；
- editorial-operations.md 含选题池、持续发布、数据记录、回滚条件；
- 对用户指定“只输出终稿”不默认展示内部工作流程。

通过标准：六份配套文件可读，以上场景没有明显违背定位、事实与用户指令的行为。人工审核文章品质不可由文件结构检查代替。
